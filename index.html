⚠️ Внимание! Этот пример использует очень маленькие числа только для обучения. Настоящие RSA-ключи используют простые числа длиной от 1024 бит и более. Закрытый ключ никогда не публикуется в открытых репозиториях!

1. Генерация ключей

  • Простые числа: p = 3, q = 5
  • Модуль: n = p × q = 15
  • Функция Эйлера: φ(n) = (p−1)(q−1) = 8
  • Открытая экспонента: e = 3 (взаимно простое с 8)
  • Закрытая экспонента: d = 3, так как (3 × 3) mod 8 = 1

2. Ключи

Открытый ключ: (n = 15, e = 3)
Закрытый ключ: (n = 15, d = 3) — ТОЛЬКО ДЛЯ УЧЕБНОГО ПРИМЕРА!

3. Шифрование и расшифровка

Сообщение: m = 2 (условие: m < n → ✅)

Шифрование: C = me mod n = 23 mod 15 = 8

Расшифровка: M = Cd mod n = 83 mod 15 = 512 mod 15 = 2 → ✅ Восстановлено!

Что такое домен?

Домен — это уникальное имя сайта в интернете, которое заменяет сложный числовой IP-адрес. Например, вместо того чтобы запоминать 142.250.189.206, вы просто вводите google.com.

Структура доменного имени

Домен состоит из нескольких частей:

  • Поддомен (необязательный): например, www в www.example.com
  • Домен второго уровня: основное имя, например, example
  • Домен верхнего уровня (TLD): расширение, например, .com, .ru, .org

Примеры доменов

  • yandex.ru — российский поисковик
  • wikipedia.org — международная энциклопедия
  • github.io — платформа для хостинга сайтов

Как зарегистрировать домен?

Чтобы получить свой домен, нужно:

  1. Выбрать свободное имя (например, myblog)
  2. Выбрать зону (например, .ru или .com)
  3. Зарегистрировать его через регистратора доменов (например, Reg.ru, GoDaddy, Namecheap)
  4. Оплатить годовое использование

После регистрации вы сможете привязать домен к своему хостингу и запустить сайт!
